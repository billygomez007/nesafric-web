# WhatsApp Utility template catalogue (U01–U30)

The approved NesAfric Utility Template Catalogue, as implemented in `src/modules/whatsapp-templates/registry.ts`. Names and bodies are copied exactly from the catalogue; `tests/fixtures/whatsapp-utility-catalogue.json` is a second, independent copy, and a unit test fails if the registry differs from it by a single character.

Defaults for all 30 (from the catalogue): category `UTILITY`, language `en`, no header, no footer, one `BODY` component, no buttons, sequential `{{1}}`, `{{2}}` … placeholders.

**Content status**

- **FINAL (16):** U01, U02, U04, U05, U06, U07, U08, U09, U11, U13, U16, U19, U20, U22, U26, U30. Catalogue text that passed every local check. Submittable after authorisation.
- **NEEDS_REVIEW (14):** U03, U10, U12, U14, U15, U17, U18, U21, U23, U24, U25, U27, U28, U29. Catalogue text that fails a local check (every one ends with a variable; eight are also variable-dense). `submit` refuses them. See `docs/whatsapp-utility-diff-report.md` section 8 for the proposed wording changes, which need catalogue approval.

Placeholder names are the registry's; the samples are what is submitted to Meta as examples. "customer" values (typed by people) have links and phone numbers removed before sending.
