# Ghana location catalogue

The native property-listing location selectors use a vendored snapshot from:

Ghana Administrative Divisions Dataset
https://github.com/open-admin-data/ghana-administrative-divisions

The upstream dataset is published under CC BY 4.0 and includes Ghana's regions,
districts/MMDAs and populated places.

The data is vendored into `ghana-locations.json` so property listing does not
depend on a third-party geography API while the user is filling the form.
